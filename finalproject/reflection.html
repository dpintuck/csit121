Reflection

I used W3Schools.com, Google.com, and my old labs to complete this project. I also borrowed animal pictures from petfinder.com. I know it's not the prettiest site, but it works (I hope). I assumed using the "Lorem ipsum" language is ok. I read it is commonly used in web development as a placeholder.

My biggest personal challenge with this assignment was getting the content to fit. I had to go back to my older labs and W3Schools to get it all to work. My biggest success was getting the hero image and text to work. This was also W3Schools to the rescue on that. The biggest insight I got from this project is that CSS makes all this a lot easier. I did not notice any issues with testing the site in other browsers or devices.

What I have learned overall from the class is that while there is code for everything, you do not need to use all of it.
